Who's That Pokémon?

A chat guessing game for your stream. Set it up below, then paste the link into OBS as a browser source.

1 Connect your Twitch account

This lets the game post announcements (like who won) in your chat. The login stays in your overlay link and is never sent to this website.

Use a bot account instead of your own

The messages can come from a separate account (e.g. YourNameBot) instead of you.

  1. Create the bot account on Twitch. Log out of your own account first, or use a private/incognito window. Verify its email so it's allowed to chat.
  2. In your own chat, type /mod botname. This stops slow mode, follower-only mode and similar settings from blocking the bot.
  3. Open this page in a private/incognito window so Twitch doesn't log you in as yourself.
  4. Click Connect with Twitch and log in as the bot account.
  5. In Settings, change Your channel to your own channel name (it fills in the bot's name by default). Then copy the link as normal.
Paste a chat token instead

Only needed if the Connect button doesn't work for you. Get a token for the account that should post the messages, for example from twitchtokengenerator.com. Choose "Bot Chat Token", log in as that account, and copy the Access Token. It needs the chat:read and chat:edit scopes. Then paste it here and set Your channel below.

3 Add it to OBS

Your settings are saved inside this link. If you change any setting later, the link changes too. Copy it again and paste it over the old URL in the OBS browser source properties. The same goes for when your Twitch login expires and you reconnect.

Keep this link private. Anyone who has it can post in your chat as you. Don't show it on stream, and if it leaks, disconnect this site from your Twitch account under Settings → Connections.
  1. In OBS: Sources → + → Browser. Leave "Local file" unticked and paste the link as the URL.
  2. Set width 800 and height 600.
  3. Untick Shutdown source when not visible.
  4. For sound: tick Control audio via OBS so the game's sounds show up in your audio mixer, where you can adjust their volume.
  5. To use it in other scenes, copy the source and use Paste (Reference).
  6. In chat, type !wtp to play.

The test page has a panel where you can type pretend chat messages. Nothing is posted to Twitch in test mode.
